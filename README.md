# Veřejná data Tipovačky Ligy mistrů

Repozitář obsahuje pouze anonymizovaný výstup pro web. Tipy jsou zveřejněny až po prvním skutečném výkopu příslušného kola. Přihlašovací údaje, e-mailové adresy, přístupové tokeny ani zdrojový master zde nejsou.

- `data.json` – aktuálně potvrzená verze
- `manifest.json` – fingerprint a cesta k aktuální verzi
- `versions/` – neměnné ověřené verze pro bezpečný rollback
